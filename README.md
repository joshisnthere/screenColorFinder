# Screen Color Picker

Click "Pick a color", then click anywhere on your screen -- any app, any
window -- and it grabs that exact pixel's color, copies the hex code to
your clipboard automatically, and keeps a history of everything you've
picked this session.

## Setup

    pip install -r requirements.txt
    python main.py

On macOS you'll need to grant Accessibility/Screen Recording permission
for the terminal or the built app the first time it asks.
